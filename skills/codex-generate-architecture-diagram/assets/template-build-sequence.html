NON-NEGOTIABLES & VERIFIED FACTS
  • Deterministic control in Apex; LLM writes words only.
  • Governor-aware: live limits guard before every send.
  • Deliverability = "System email only" while building.
  • No external apps/servers (EAC rejected — Path B native).
  • Async: Batch (50) → Queueable → LLM (never call out in execute()).
  • Logs + heartbeat are mandatory for observability.
  • Sandbox-first build & validation; keys in Named Credentials.
  • Scope v1 = Lead drip only; Scope 3 (Flow) NOT validated in v1.
