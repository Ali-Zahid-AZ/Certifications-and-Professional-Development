Control / Intelligence Boundary — the safety backbone
Deterministic Apex decides
WHO · WHEN · WHICH STEP · SEND-OR-SKIP · STOP-AFTER-REPLY
The LLM decides only
The SUBJECT LINE and the BODY TEXT — then it is validated.
LLM output never feeds back into control flow. An AI mistake can at worst produce a weak email (caught → template), never a wrong send.
Key guarantees
  • Never sends if not eligible (deterministic guard).
  • Never sends after a reply (stop-on-reply).
  • LLM failure → template fallback (email always sent, never blocked).
  • Idempotency + re-checks → no duplicate sends.
  • Full telemetry + daily heartbeat → fully auditable.
